# RICOCHET OVERDRIVE

スマホ縦画面特化のハイスピード・ネオンピンボールアクション（HTML5 Canvas + Web Audio API、単一ファイル完結）。

## 操作方法（スマホ）
- **画面の左半分 / 右半分をタップ**：左右フリッパー（両手同時押し対応・ジャスト強打で2.5倍貫通クリティカル）
- **上スワイプ / 下部「⚡ 揺らす」ボタン**：台揺らし衝撃波（TILT 100%で一時ロック）

## GitHub Pages 公開手順
1. このフォルダをGitHubリポジトリに Push します。
2. GitHub のリポジトリ画面で **Settings → Pages** を開きます。
3. **Build and deployment** の Source を **Deploy from a branch**、Branch を **`main` / `/ (root)`** に設定して Save すると数分で公開URLが発行されます。
